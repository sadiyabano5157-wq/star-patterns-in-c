# ⭐ Star Pattern (Increasing Triangle) in C

## 📌 Description
This program prints a simple star pattern in increasing order using nested loops in C language

## 💡 Pattern Output
*
* *
* * *
* * * *
* * * * *

---

## 🧠 Concept Used
- Nested loops
- Outer loop → rows
- Inner loop → stars printing

---

## ⚙️ Logic

- Outer loop controls number of rows
- Inner loop controls number of stars in each row
